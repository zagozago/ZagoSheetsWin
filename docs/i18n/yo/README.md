**Ṣí àwọn fáìlì spreadsheet tó wà lórí kọ̀ǹpútà rẹ tààrà nínú Google Sheets láti Windows.**

ZagoSheetsWin jẹ́ ìṣàfilọ́lẹ̀ Windows kékeré tó mú kí ṣíṣí spreadsheet tó wà lórí kọ̀ǹpútà rọrùn:

**tẹ fáìlì lẹ́ẹ̀mejì → gbé e sórí ayélujára kí o sì yí i padà → ṣí i nínú Google Sheets**

Lẹ́yìn tí gbígbé wọlé bá ṣàṣeyọrí, ZagoSheetsWin lè fi ọ̀nà abuja Íńtánẹ́ẹ̀tì (`.url`) tó tọ́ka sí ìwé Google Sheets rọ́pò fáìlì àkọ́kọ́. Yóò sì pa ẹ̀dà àfikún fáìlì àkọ́kọ́ mọ́ sórí kọ̀ǹpútà kí a lè dá a padà.

Ète rẹ̀ rọrùn: kí Google Sheets lè ṣí àwọn spreadsheet inú kọ̀ǹpútà bí ìṣàfilọ́lẹ̀ Windows tó wọ́pọ̀.

## Ohun tí ó ń ṣe

ZagoSheetsWin ń so àwọn fáìlì spreadsheet Windows pọ̀ mọ́ Google Sheets. Tí o bá ṣí fáìlì tó bá iṣẹ́ rẹ̀ mu, ó lè:

- dá spreadsheet mọ̀, kí ó sì ṣàyẹ̀wò rẹ̀;
- dá ẹ̀dà àfikún tí a lè mú padà;
- gbé fáìlì tààrà sí Google Drive nípasẹ̀ API ìjọba Google;
- yí i padà sí ìwé Google Sheets gidi;
- ṣí àbájáde náà nínú browser aiyipada;
- dá ọ̀nà abuja `.url` sí ìwé Google;
- yẹra fún fífi fáìlì kan náà ránṣẹ́ lẹ́ẹ̀kansi nígbà tí a bá tún ṣí i.

Kò sí dandan láti gbé fáìlì sí Drive pẹ̀lú ọwọ́, wá a nínú browser, tàbí máa yí i padà léraléra.

## Àwọn irú fáìlì tí a ń ṣe àtìlẹ́yìn fún

Àwọn irú fáìlì tí ìdàgbàsókè ń fojú sí báyìí ni `.xlsx`, `.xls`, `.ods`, `.csv` àti `.tsv`.

Àwọn irú kan lè ní ààlà ìbámu míràn. A máa ṣọ́ra pẹ̀lú fáìlì tó ní àwọn àbùdá tí kò ṣeé pa mọ́ láìsí ewu, kí dátà má bàa sọnù láìjẹ́ kí oníṣe mọ̀.

## A ṣe é fún Windows

A kọ ZagoSheetsWin pàtó fún Windows. Ó ní **Open with (Ṣí pẹ̀lú)**, ìforúkọsílẹ̀ irú fáìlì, ṣíṣí pẹ̀lú títẹ lẹ́ẹ̀mejì, ìsopọ̀ File Explorer tí a lè yan, àti ohun èlò fifi sori Windows.

Kò yí ìṣàfilọ́lẹ̀ aiyipada Windows padà ní ìkọ̀kọ̀. Oníṣe ló ń ṣàkóso ìbáṣepọ̀ fáìlì.

## Ààbò láti ìpilẹ̀

Ríròpo fáìlì inú kọ̀ǹpútà jẹ́ iṣẹ́ tí a gbọ́dọ̀ lè mú padà. Kí a tó yọ fáìlì àkọ́kọ́ kúrò nínú folder rẹ̀, ìṣàfilọ́lẹ̀ náà máa jẹ́rìí pé:

1. ẹ̀dà àfikún tí a lè mú padà wà;
2. a ti dá ìwé Google Sheets sílẹ̀ dáadáa;
3. a ti fi ìbáṣepọ̀ fáìlì pamọ́ títí;
4. a ti kọ ọ̀nà abuja Íńtánẹ́ẹ̀tì, a sì ti dán an wò.

Tí iṣẹ́ bá kùnà, fáìlì àkọ́kọ́ yóò wà ní ààbò.

> Má ṣe pa dátà oníṣe run láìjẹ́ kí oníṣe mọ̀.

## Àwọn ẹ̀dà àfikún

A lè fi àwọn fáìlì àkọ́kọ́ pamọ́ sí ibi àfikún aládàáni lórí kọ̀ǹpútà kí a tó fi ọ̀nà abuja rọ́pò wọn. A lè ṣètò ìwọ̀n ibi ìpamọ́, iye ọjọ́ tí a máa fi pamọ́ àti ọ̀nà ìmúmọ́.

Ẹ̀dà àfikún ń dáàbò bo fáìlì ní àkókò tí a gbé e wọlé. **Kì í ṣe ìṣiṣẹ́pọ̀ ọ̀nà méjì**: àwọn àtúnṣe tí o bá ṣe lẹ́yìn náà nínú Google Sheets kò ní padà sí fáìlì spreadsheet àkọ́kọ́.

## Ìpamọ́ àti ìwọlé Google

ZagoSheetsWin ń bá API Google sọ̀rọ̀ tààrà láti kọ̀ǹpútà rẹ.

- A kò rán ohun tó wà nínú spreadsheet sí server Zagotools.
- A ń pa token OAuth mọ́ lórí kọ̀ǹpútà, ààbò Windows sì ń dáàbò bò ó.
- Àṣẹ `drive.file` ń dín ìwọlé kù sí àwọn fáìlì tí a dá tàbí ṣí nípasẹ̀ ìṣàfilọ́lẹ̀.
- Kò nílò ìtọpinpin ìṣirò fún ìgbéwọlé spreadsheet.

Ìlànà Ìpamọ́ àti Àwọn Òfin Ìlò: https://zagotools.top/legal.html

## Ipò iṣẹ́ náà

A ṣì ń ṣe àgbékalẹ̀ ZagoSheetsWin; ó jẹ́ **sọ́fitiwia ìpele alpha** báyìí. Ọ̀nà pàtàkì Windows → Google Sheets ń ṣiṣẹ́. A ń tún fifi sori, ìmúpadàbọ̀, ìbámu fáìlì, ìtúmọ̀ èdè àti ìrírí oníṣe ṣe. Àwọn àyípadà lè wá ṣáájú ẹ̀yà ìdúróṣinṣin àkọ́kọ́.

## Ìbáṣepọ̀ pẹ̀lú Open in Google

ZagoSheetsWin jẹ́ iṣẹ́ tí a dá lórí [Open in Google](https://github.com/SwatiK425/open-in-google) ti [SwatiK425](https://github.com/SwatiK425). Iṣẹ́ yẹn ni ó fún wa ní ìpilẹ̀ àti ìmísí àkọ́kọ́.

ZagoSheetsWin ti di ìṣàfilọ́lẹ̀ Windows olómìnira pẹ̀lú ìṣètò, ohun fifi sori, ojú-ìbáṣepọ̀, ẹ̀dà àfikún àti ìmúpadàbọ̀, ìbáṣepọ̀ fáìlì, ìtọ́jú àwọn format, àti ọ̀nà ṣíṣí fáìlì nínú Google Sheets tirẹ̀. Iṣẹ́ àkọ́kọ́ ń ṣiṣẹ́ lọ́tọ̀, a sì lè dá àwọn àtúnṣe gbogboogbo padà sí upstream tí ó bá yẹ.
