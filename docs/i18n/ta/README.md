ZagoSheetsWin என்பது உள்ளூர் விரிதாள்களைத் திறப்பதை எளிதாக்கும் இலகுவான Windows செயலியாகும்:

**கோப்பை இருமுறை கிளிக் → பதிவேற்றி மாற்று → Google Sheets-இல் திற**

இறக்குமதி வெற்றியடைந்த பிறகு, அசல் உள்ளூர் கோப்புக்குப் பதிலாக Google Sheets ஆவணத்திற்கான இணையக் குறுக்குவழியை (`.url`) ZagoSheetsWin உருவாக்கலாம். அசல் கோப்பின் மீட்டெடுக்கக்கூடிய உள்ளூர் காப்புப்பிரதியும் பாதுகாக்கப்படும்.

உள்ளூர் விரிதாள் கோப்புகளைத் திறக்கும்போது Google Sheets வழக்கமான Windows செயலியைப் போல இயங்க வேண்டும் என்பதே நோக்கம்.

## இது என்ன செய்கிறது

ZagoSheetsWin Windows விரிதாள் கோப்புகளை Google Sheets உடன் இணைக்கிறது. ஆதரிக்கப்படும் உள்ளூர் கோப்பைத் திறக்கும்போது செயலி:

- விரிதாளைக் கண்டறிந்து சரிபார்க்கலாம்;
- மீட்டெடுக்கக்கூடிய காப்புப்பிரதியை உருவாக்கலாம்;
- Google-இன் அதிகாரப்பூர்வ API வழியாக நேரடியாக Google Drive-க்கு பதிவேற்றலாம்;
- Google Sheets-இன் சொந்த ஆவண வடிவத்திற்கு மாற்றலாம்;
- முடிவை இயல்புநிலை உலாவியில் திறக்கலாம்;
- Google ஆவணத்திற்கான உள்ளூர் `.url` குறுக்குவழியை உருவாக்கலாம்;
- பின்னர் அதே கோப்பைத் திறக்கும் போது மீண்டும் பதிவேற்றுவதைத் தவிர்க்கலாம்.

Drive-க்கு கைமுறையாகப் பதிவேற்றவோ, உலாவியில் கோப்பைத் தேடவோ, மாற்றத்தை மீண்டும் மீண்டும் செய்யவோ தேவையில்லை.

## ஆதரிக்கப்படும் வடிவங்கள்

தற்போதைய மேம்பாட்டின் இலக்கு வடிவங்கள்: `.xlsx`, `.xls`, `.ods`, `.csv`, `.tsv`.

சில வடிவங்களுக்கு கூடுதல் இணக்க வரம்புகள் இருக்கலாம். பாதுகாப்பாகத் தக்கவைக்க முடியாத அம்சங்களைக் கொண்ட கோப்புகள், எச்சரிக்கையின்றித் தரவு இழப்பு ஏற்படாத வகையில் கவனமாகக் கையாளப்படும்.

## Windows-க்காக வடிவமைக்கப்பட்டது

ZagoSheetsWin Windows-க்காகவே உருவாக்கப்பட்டுள்ளது. இதில் **Open with (இதனுடன் திற)**, கோப்பு வகைப் பதிவு, இருமுறை கிளிக் செய்து திறத்தல், விருப்பத்திற்கேற்ப File Explorer ஒருங்கிணைப்பு, சொந்த Windows நிறுவி ஆகியவை உள்ளன.

செயலி உங்களுக்குத் தெரியாமல் Windows இயல்புநிலைச் செயலிகளை மாற்றாது. கோப்பு இணைப்புகளைக் கட்டுப்படுத்துவது பயனரின் உரிமை.

## வடிவமைப்பிலேயே பாதுகாப்பு

உள்ளூர் கோப்பை மாற்றுவது மீட்டெடுக்கக்கூடிய செயலாகக் கருதப்படுகிறது. அசல் கோப்பை அதன் கோப்புறையிலிருந்து அகற்றும் முன் செயலி உறுதிப்படுத்துவது:

1. மீட்டெடுக்கக்கூடிய காப்புப்பிரதி உள்ளது;
2. Google Sheets ஆவணம் வெற்றிகரமாக உருவாக்கப்பட்டது;
3. உள்ளூர் கோப்பு இணைப்பு நிரந்தரமாகச் சேமிக்கப்பட்டது;
4. இணையக் குறுக்குவழி சரியாக எழுதப்பட்டு சரிபார்க்கப்பட்டது.

செயல் தோல்வியடைந்தால் அசல் கோப்பு பாதுகாக்கப்படும்.

> பயனருக்குத் தெரியாமல் அவரின் தரவை ஒருபோதும் அழிக்கக்கூடாது.

## காப்புப்பிரதிகள்

அசல் கோப்புகளைக் குறுக்குவழிகளால் மாற்றுவதற்கு முன் தனிப்பட்ட உள்ளூர் காப்புப்பிரதிப் பகுதியில் சேமிக்கலாம். சேமிப்பு வரம்பு, வைத்திருக்கும் காலம், சுத்தப்படுத்தும் விருப்பங்களை அமைக்கலாம்.

காப்புப்பிரதி முதலில் இறக்குமதி செய்த கோப்பைப் பாதுகாக்கிறது. இது **இருவழி ஒத்திசைவு அல்ல**: Google Sheets-இல் பின்னர் செய்யப்படும் மாற்றங்கள் அசல் விரிதாள் கோப்பில் மீண்டும் எழுதப்படாது.
