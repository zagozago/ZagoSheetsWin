**Windows مان پنهنجي ڪمپيوٽر جون مقامي اسپريڊ شيٽ فائلون سڌو Google Sheets ۾ کوليو.**

ZagoSheetsWin هڪ هلڪي Windows ايپليڪيشن آهي، جيڪا مقامي اسپريڊ شيٽ کولڻ کي آسان بڻائي ٿي:

**فائل تي ٻه ڀيرا ڪلڪ → اپ لوڊ ۽ تبديل ڪريو → Google Sheets ۾ کوليو**

ڪامياب درآمد کان پوءِ ZagoSheetsWin اصل مقامي فائل جي جاءِ تي انٽرنيٽ شارٽ ڪٽ (`.url`) رکي سگهي ٿي، جيڪو Google Sheets دستاويز ڏانهن وٺي وڃي ٿو. اصل فائل جو ٻيهر حاصل ڪري سگهجندڙ مقامي بيڪ اپ پڻ محفوظ رهندو آهي.

مقصد سادو آهي: مقامي اسپريڊ شيٽ فائلون کولڻ وقت Google Sheets کي عام Windows ايپليڪيشن وانگر استعمال ڪرڻ.

## هي ڇا ڪري ٿي

ZagoSheetsWin، Windows جي اسپريڊ شيٽ فائلن کي Google Sheets سان ڳنڍي ٿي. سهڪار ڪيل مقامي فائل کولڻ وقت ايپ:

- اسپريڊ شيٽ کي سڃاڻي ۽ جانچي سگهي ٿي؛
- بحال ڪري سگهجندڙ بيڪ اپ ٺاهي سگهي ٿي؛
- Google جي سرڪاري API ذريعي فائل سڌو Google Drive تي اپ لوڊ ڪري سگهي ٿي؛
- ان کي اصل Google Sheets دستاويز ۾ تبديل ڪري سگهي ٿي؛
- ٺهيل اسپريڊ شيٽ ڊيفالٽ برائوزر ۾ کولي سگهي ٿي؛
- Google دستاويز لاءِ مقامي `.url` شارٽ ڪٽ ٺاهي سگهي ٿي؛
- ايندڙ ڀيري ساڳي فائل کولڻ تي ٻيهر اپ لوڊ ڪرڻ کان بچي سگهي ٿي.

Drive تي هٿ سان اپ لوڊ ڪرڻ، برائوزر ۾ فائل ڳولڻ يا بار بار تبديل ڪرڻ جي ضرورت ناهي.

## سهڪار ڪيل فارميٽ

هن وقت ترقي هيٺ هدف فارميٽ: `.xlsx`، `.xls`، `.ods`، `.csv` ۽ `.tsv`.

ڪجهه فارميٽن ۾ وڌيڪ مطابقت جون حدون ٿي سگهن ٿيون. جن فائلن جون ڪي خاصيتون محفوظ نموني برقرار نٿيون رکي سگهجن، تن کي احتياط سان سنڀاليو وڃي ٿو ته جيئن صارف کي اطلاع کان سواءِ ڊيٽا ضايع نه ٿئي.

## Windows لاءِ ٺاهيل

ZagoSheetsWin خاص Windows لاءِ ٺاهيل آهي ۽ **Open with (هن سان کوليو)**، فائل جي قسم جي رجسٽريشن، ٻه ڀيرا ڪلڪ ڪري کولڻ، اختياري File Explorer انضمام ۽ اصل Windows انسٽالر کي سهارو ڏئي ٿي.

ايپ صارف کي ٻڌائڻ کان سواءِ Windows جون ڊيفالٽ ايپس نٿي بدلائي. فائلن جي لاڳاپن تي ڪنٽرول صارف وٽ رهي ٿو.

## شروعات کان حفاظت

مقامي فائل جي بدلي اهڙو عمل آهي جيڪو واپس بحال ڪري سگهجي. اصل فائل کي فولڊر مان هٽائڻ کان اڳ ايپ تصديق ڪري ٿي ته:

1. بحال ڪري سگهجندڙ بيڪ اپ موجود آهي؛
2. Google Sheets دستاويز ڪاميابي سان ٺهي ويو آهي؛
3. مقامي فائل جو لاڳاپو مستقل نموني محفوظ ٿيو آهي؛
4. انٽرنيٽ شارٽ ڪٽ لکجي ۽ جانچجي ويو آهي.

جيڪڏهن عمل ناڪام ٿئي ته اصل فائل محفوظ رهندي.

> صارف کي اطلاع کان سواءِ سندس ڊيٽا ڪڏهن به تباهه نه ڪريو.

## بيڪ اپ

اصل فائلن کي شارٽ ڪٽ سان بدلائڻ کان اڳ خانگي مقامي بيڪ اپ جاءِ ۾ رکي سگهجي ٿو. اسٽوريج جون حدون، محفوظ رکڻ جو مدو ۽ صفائي جا اختيار ترتيب ڏئي سگهجن ٿا.

بيڪ اپ درآمد واري وقت جي اصل فائل کي محفوظ ڪري ٿو. اهو **ٻن طرفن وارو هم وقت سازي نظام ناهي**: بعد ۾ Google Sheets ۾ ٿيل تبديليون اصل اسپريڊ شيٽ فائل ۾ واپس نه لکيون وينديون.

## رازداري ۽ Google تائين رسائي

ZagoSheetsWin توهان جي ڪمپيوٽر مان سڌو Google API سان رابطو ڪري ٿي.

- توهان جي اسپريڊ شيٽ جو مواد Zagotools جي سرورن ڏانهن نه موڪليو ويندو.
- OAuth ٽوڪن مقامي طور محفوظ ڪيا وڃن ٿا ۽ Windows جي حفاظتي نظام سان بچايا وڃن ٿا.
- `drive.file` اجازت جو دائرو انهن فائلن تائين رسائي محدود ڪري ٿو جيڪي ايپ ذريعي ٺاهيون يا کوليون ويون آهن.
- اسپريڊ شيٽ درآمد لاءِ تجزياتي ٽريڪنگ ضروري ناهي.

رازداري پاليسي ۽ استعمال جا شرط: https://zagotools.top/legal.html

## منصوبي جي حالت

ZagoSheetsWin تي فعال ترقي جاري آهي ۽ هن وقت اهو **الفا مرحلي جو سافٽ ويئر** آهي. Windows → Google Sheets جو مکيه عمل ڪم ڪري رهيو آهي. انسٽاليشن، بحالي، فارميٽ مطابقت، گهڻ ٻوليون ۽ استعمال ڪندڙ جو تجربو وڌيڪ بهتر ڪيو پيو وڃي. پهرئين مستحڪم ورزن کان اڳ تبديليون ٿي سگهن ٿيون.

## Open in Google سان لاڳاپو

ZagoSheetsWin، [SwatiK425](https://github.com/SwatiK425) جي [Open in Google](https://github.com/SwatiK425/open-in-google) منصوبي تي ٻڌل آهي ۽ ان مان ترقي ڪئي وئي آهي. اصل منصوبي شروعاتي بنياد ۽ خيال مهيا ڪيو.

هاڻي ZagoSheetsWin هڪ آزاد Windows ايپ آهي، جنهن وٽ پنهنجي بناوت، انسٽالر، انٽرفيس، بيڪ اپ ۽ بحالي، فائل لاڳاپا، فارميٽ سنڀالڻ ۽ مقامي فائلن کي Google Sheets ۾ کولڻ جو طريقو آهي. اصل منصوبو آزاد رهي ٿو؛ مناسب عام بهتريون upstream کي پيش ڪري سگهجن ٿيون.
