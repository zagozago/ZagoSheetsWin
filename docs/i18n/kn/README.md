**Windows ನಿಂದ ಸ್ಥಳೀಯ ಸ್ಪ್ರೆಡ್‌ಶೀಟ್ ಫೈಲ್‌ಗಳನ್ನು ನೇರವಾಗಿ Google Sheets ನಲ್ಲಿ ತೆರೆಯಿರಿ.**

ZagoSheetsWin ಎನ್ನುವುದು ಸ್ಥಳೀಯ ಸ್ಪ್ರೆಡ್‌ಶೀಟ್ ತೆರೆಯುವುದನ್ನು ಸರಳಗೊಳಿಸುವ ಹಗುರವಾದ Windows ಅಪ್ಲಿಕೇಶನ್ ಆಗಿದೆ:

**ಫೈಲ್ ಮೇಲೆ ಎರಡು ಬಾರಿ ಕ್ಲಿಕ್ → ಅಪ್‌ಲೋಡ್ ಮತ್ತು ಪರಿವರ್ತನೆ → Google Sheets ನಲ್ಲಿ ತೆರೆಯಿರಿ**

ಆಮದು ಯಶಸ್ವಿಯಾದ ನಂತರ, ZagoSheetsWin ಮೂಲ ಸ್ಥಳೀಯ ಫೈಲ್ ಬದಲು Google Sheets ದಾಖಲೆಗೆ ಕೊಂಡಿಯಾಗಿರುವ ಇಂಟರ್ನೆಟ್ ಶಾರ್ಟ್‌ಕಟ್ (`.url`) ಅನ್ನು ಇರಿಸಬಹುದು. ಜೊತೆಗೆ ಮೂಲ ಫೈಲ್‌ನ ಮರುಪಡೆಯಬಹುದಾದ ಸ್ಥಳೀಯ ಬ್ಯಾಕಪ್ ಅನ್ನು ಉಳಿಸಿಕೊಳ್ಳುತ್ತದೆ.

ಉದ್ದೇಶ ಸರಳ: ಸ್ಥಳೀಯ ಸ್ಪ್ರೆಡ್‌ಶೀಟ್‌ಗಳನ್ನು ತೆರೆಯಲು Google Sheets ಅನ್ನು ಸಾಮಾನ್ಯ Windows ಅಪ್ಲಿಕೇಶನ್‌ನಂತೆ ಬಳಸಲು ಸಾಧ್ಯವಾಗಬೇಕು.

## ಇದು ಏನು ಮಾಡುತ್ತದೆ

ZagoSheetsWin Windows ನ ಸ್ಪ್ರೆಡ್‌ಶೀಟ್ ಫೈಲ್‌ಗಳನ್ನು Google Sheets ಜೊತೆಗೆ ಸಂಪರ್ಕಿಸುತ್ತದೆ. ಬೆಂಬಲಿತ ಸ್ಥಳೀಯ ಫೈಲ್ ಅನ್ನು ತೆರೆದಾಗ ಅಪ್ಲಿಕೇಶನ್:

- ಸ್ಪ್ರೆಡ್‌ಶೀಟ್ ಗುರುತಿಸಿ ಪರಿಶೀಲಿಸಬಹುದು;
- ಮರುಪಡೆಯಬಹುದಾದ ಬ್ಯಾಕಪ್ ಸೃಷ್ಟಿಸಬಹುದು;
- Google ನ ಅಧಿಕೃತ API ಗಳ ಮೂಲಕ ನೇರವಾಗಿ Google Drive ಗೆ ಅಪ್‌ಲೋಡ್ ಮಾಡಬಹುದು;
- ಅದನ್ನು Google Sheets ನ ಸ್ಥಳೀಯ ದಾಖಲೆಯಾಗಿ ಪರಿವರ್ತಿಸಬಹುದು;
- ಫಲಿತಾಂಶವನ್ನು ಡೀಫಾಲ್ಟ್ ಬ್ರೌಸರ್‌ನಲ್ಲಿ ತೆರೆಯಬಹುದು;
- Google ದಾಖಲೆಗೆ ಸ್ಥಳೀಯ `.url` ಶಾರ್ಟ್‌ಕಟ್ ರಚಿಸಬಹುದು;
- ನಂತರ ಅದೇ ಫೈಲ್ ತೆರೆಯುವಾಗ ಮರು ಅಪ್‌ಲೋಡ್ ತಪ್ಪಿಸಬಹುದು.

Drive ಗೆ ಕೈಯಾರೆ ಅಪ್‌ಲೋಡ್ ಮಾಡುವ, ಬ್ರೌಸರ್‌ನಲ್ಲಿ ಹುಡುಕುವ ಅಥವಾ ಮತ್ತೆ ಮತ್ತೆ ಪರಿವರ್ತಿಸುವ ಅಗತ್ಯವಿಲ್ಲ.

## ಬೆಂಬಲಿತ ಫಾರ್ಮ್ಯಾಟ್‌ಗಳು

ಪ್ರಸ್ತುತ ಅಭಿವೃದ್ಧಿಯ ಗುರಿಯಾಗಿರುವ ಫಾರ್ಮ್ಯಾಟ್‌ಗಳು: `.xlsx`, `.xls`, `.ods`, `.csv` ಮತ್ತು `.tsv`.

ಕೆಲವು ಫಾರ್ಮ್ಯಾಟ್‌ಗಳಿಗೆ ಹೆಚ್ಚುವರಿ ಹೊಂದಾಣಿಕೆಯ ಮಿತಿಗಳಿರಬಹುದು. ಸುರಕ್ಷಿತವಾಗಿ ಉಳಿಸಲಾಗದ ವೈಶಿಷ್ಟ್ಯಗಳಿರುವ ಫೈಲ್‌ಗಳನ್ನು ಎಚ್ಚರಿಕೆಯಿಂದ ನಿರ್ವಹಿಸಲಾಗುತ್ತದೆ, ಬಳಕೆದಾರರಿಗೆ ತಿಳಿಯದೆ ಡೇಟಾ ಕಳೆದುಹೋಗುವುದನ್ನು ತಪ್ಪಿಸಲು.

## Windows ಗಾಗಿ ವಿನ್ಯಾಸ

ZagoSheetsWin ಅನ್ನು ವಿಶೇಷವಾಗಿ Windows ಗಾಗಿ ನಿರ್ಮಿಸಲಾಗಿದೆ. ಇದರಲ್ಲಿ **Open with (ಇದರೊಂದಿಗೆ ತೆರೆಯಿರಿ)**, ಫೈಲ್ ಪ್ರಕಾರಗಳ ನೋಂದಣಿ, ಡಬಲ್-ಕ್ಲಿಕ್ ಮೂಲಕ ತೆರೆಯುವುದು, ಐಚ್ಛಿಕ File Explorer ಸಂಯೋಜನೆ ಮತ್ತು ಸ್ಥಳೀಯ Windows ಇನ್‌ಸ್ಟಾಲರ್ ಇವೆ.

ಬಳಕೆದಾರರಿಗೆ ತಿಳಿಸದೆ ಡೀಫಾಲ್ಟ್ Windows ಅಪ್ಲಿಕೇಶನ್‌ಗಳನ್ನು ಬದಲಾಯಿಸುವುದಿಲ್ಲ. ಫೈಲ್ ಸಂಬಂಧಗಳ ನಿಯಂತ್ರಣ ಬಳಕೆದಾರರಲ್ಲೇ ಇರುತ್ತದೆ.

## ವಿನ್ಯಾಸದಲ್ಲೇ ಸುರಕ್ಷತೆ

ಸ್ಥಳೀಯ ಫೈಲ್ ಬದಲಿಸುವುದು ಮರುಪಡೆಯಬಹುದಾದ ಕಾರ್ಯಾಚರಣೆಯಾಗಿದೆ. ಮೂಲ ಫೈಲ್ ಅನ್ನು ಅದರ ಫೋಲ್ಡರ್‌ನಿಂದ ತೆಗೆದುಹಾಕುವ ಮೊದಲು ಅಪ್ಲಿಕೇಶನ್ ಇವುಗಳನ್ನು ಖಚಿತಪಡಿಸುತ್ತದೆ:

1. ಮರುಪಡೆಯಬಹುದಾದ ಬ್ಯಾಕಪ್ ಇದೆ;
2. Google Sheets ದಾಖಲೆ ಯಶಸ್ವಿಯಾಗಿ ಸೃಷ್ಟಿಯಾಗಿದೆ;
3. ಸ್ಥಳೀಯ ಫೈಲ್ ಸಂಬಂಧವನ್ನು ಶಾಶ್ವತವಾಗಿ ಉಳಿಸಲಾಗಿದೆ;
4. ಇಂಟರ್ನೆಟ್ ಶಾರ್ಟ್‌ಕಟ್ ಬರೆದು ಪರಿಶೀಲಿಸಲಾಗಿದೆ.

ಪ್ರಕ್ರಿಯೆ ವಿಫಲವಾದರೆ ಮೂಲ ಫೈಲ್ ಉಳಿಯುತ್ತದೆ.

> ಬಳಕೆದಾರರಿಗೆ ತಿಳಿಸದೆ ಅವರ ಡೇಟಾವನ್ನು ಎಂದಿಗೂ ನಾಶ ಮಾಡಬೇಡಿ.

ಶಾರ್ಟ್‌ಕಟ್‌ಗಳಿಂದ ಬದಲಿಸುವ ಮೊದಲು ಮೂಲ ಫೈಲ್‌ಗಳನ್ನು ಖಾಸಗಿ ಸ್ಥಳೀಯ ಬ್ಯಾಕಪ್ ಪ್ರದೇಶದಲ್ಲಿ ಉಳಿಸಬಹುದು. ಸಂಗ್ರಹ ಮಿತಿ, ಉಳಿಸುವ ಅವಧಿ ಮತ್ತು ಸ್ವಚ್ಛಗೊಳಿಸುವ ಆಯ್ಕೆಗಳನ್ನು ಹೊಂದಿಸಬಹುದು.
